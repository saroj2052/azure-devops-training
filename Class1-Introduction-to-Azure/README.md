# Class 1: Introduction to Azure and Cloud Administration

## Course Overview
Welcome to the Azure and Cloud Administration training program! This is Class 1 where we will establish a foundational understanding of cloud computing, Azure services, and cloud infrastructure management.

## 📚 Learning Objectives
By the end of this class, participants will:
- Understand core cloud computing concepts and deployment models
- Identify differences between IaaS, PaaS, and SaaS
- Navigate Azure's global infrastructure and organizational hierarchy
- Organize and manage Azure resources effectively
- Design basic cloud infrastructure for multi-region scenarios

## ⏱️ Session Duration
- **Estimated Time**: 4 hours
- **Format**: Interactive lecture + Hands-on Activity

## 📋 Topics Covered

### 1. What is Cloud Computing? (30 min)
- Definition and characteristics
- Benefits and challenges
- On-premises vs. Cloud computing comparison
- Real-world use cases

### 2. Cloud Deployment Models (45 min)
- **Public Cloud**: Azure, AWS, GCP
- **Private Cloud**: On-premises or dedicated infrastructure
- **Hybrid Cloud**: Combining multiple models
- When to use each model

### 3. Cloud Service Models (45 min)
- **IaaS** (Infrastructure as a Service)
- **PaaS** (Platform as a Service)
- **SaaS** (Software as a Service)
- Service responsibility matrix

### 4. Azure Global Infrastructure (30 min)
- Azure Regions and their characteristics
- Availability Zones for high availability
- Region pairs and disaster recovery
- Data residency considerations

### 5. Azure Resource Organization (30 min)
- Subscriptions: Management and billing
- Resource Groups: Logical containers
- Resource hierarchy
- Naming conventions and organization strategies

### 6. Azure Portal Walkthrough (20 min)
- Portal navigation
- Resource creation workflow
- Key services and tools
- Hands-on portal exploration

## 🎯 Interactive Activity
**Project: Design Multi-Region Azure Infrastructure**
- Scenario: Your company operates in North America, Europe, and Asia
- Task: Design an Azure structure with proper resource organization
- Deliverables: Resource hierarchy diagram, subscription strategy, region selection

## ✅ Key Outcomes
- Participants understand Azure's organizational structure
- Ability to design basic Azure architectures
- Familiarity with Azure Portal
- Foundation for advanced DevOps topics
